# Chat4Meet — Website

## Platform

`web` — statische Marketing-Landing (Astro), später GitHub Pages.

## Stack

- Astro 4, Tailwind CSS 3, TypeScript strict
- Deploy-Ziel: GitHub Pages (`/website-chat4meet` base path)
- Delegiert von Plan; Node auf Entwicklungsrechnern ≥ 20 empfohlen

## Product

**Chat4Meet** ist eine Flutter-App für **Chat**, **Stories** und **Profile**.

Diese Website ist die **öffentliche Präsenz** der App: kurze Erklärung, CI wie die App, Download-Hinweis — keine App-Funktionalität im Browser.

## Audience

- People discovering Chat4Meet before download
- Bestehende Nutzer, die die Marke wiedererkennen sollen
- Situation: kurzer Besuch, mobil oder Desktop

## Positioning

Tagline (EN, from app): **“Real connections. Safe and direct.”**

Keine erfundenen Kunden, Bewertungen oder Feature-Versprechen über das App-Angebot hinaus.

## Brand commitments

- Primärfarbe: `#009C9C` (App `brandTeal`)
- Typografie: **Ubuntu** (wie `AppTypography`)
- Text: `#111418`, muted `#6B7280`; helle Sektionen `#F9FAFB`
- Logos/Icons aus dem Chat4Meet-App-Repository

## Open decisions

- App Store / Google Play URLs (Platzhalter bis Veröffentlichung)
- Impressum & Datenschutz (Phase 2 vor öffentlichem DE-Hosting)
- Custom Domain vs. `github.io/website-chat4meet`

## Accessibility

- Deutsche Hauptsprache (`lang="de"`)
- Semantische Sektionen, sinnvolle Überschriftenhierarchie
- Store-Buttons als disabled, bis echte Links hinterlegt sind
